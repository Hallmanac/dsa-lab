# Curriculum

Work through Core topics roughly in order. Each builds on patterns from the
ones before it. Advanced topics can be tackled in any order once the Core
list is solid, or pulled in early if a specific one comes up in coursework.

Each topic has a directory slug in parentheses. `/lesson` uses these to
create and find `lessons/<slug>/`, so keep them stable if you ever edit
this file.

## Core

1. Big-O notation & complexity analysis (`01-big-o`)
2. Arrays & strings basics (`02-arrays-strings`)
3. Two pointers (`03-two-pointers`)
4. Sliding window (`04-sliding-window`)
5. Hashing — hash maps & sets (`05-hashing`)
6. Sorting algorithms (`06-sorting`)
7. Binary search (`07-binary-search`)
8. Recursion basics (`08-recursion`)
9. Linked lists (`09-linked-lists`)
10. Stacks & queues (`10-stacks-queues`)
11. Trees — binary trees, BSTs, traversals (`11-trees`)
12. Heaps / priority queues (`12-heaps`)
13. Graphs — BFS & DFS (`13-graphs`)
14. Backtracking (`14-backtracking`)
15. Dynamic programming — 1D (`15-dp-1d`)
16. Dynamic programming — 2D / grid (`16-dp-2d`)
17. Greedy algorithms (`17-greedy`)

## Advanced / less common

18. Tries (`18-tries`)
19. Union-Find / disjoint set (`19-union-find`)
20. Segment trees & Fenwick trees (`20-segment-trees`)
21. Topological sort (`21-topological-sort`)
22. Shortest-path algorithms — Dijkstra's, Bellman-Ford (`22-shortest-path`)
23. Bit manipulation (`23-bit-manipulation`)
24. Advanced string matching — KMP, Rabin-Karp (`24-string-matching`)
25. Bitmask DP (`25-bitmask-dp`)
26. Monotonic stack / monotonic queue (`26-monotonic-stack`)
27. Interval scheduling problems (`27-interval-scheduling`)

## Notes

- If a topic-language pair gets logged in `progress/PROGRESS.md` with
  confidence 3 or below, treat it as a candidate to revisit before moving
  further down this list, even if later topics don't strictly depend on it.
- It's fine to go out of order if something's come up in class or a
  problem set. Just note in the progress log that it was out of sequence.
